Amazon Price Tracker Using Python

This project automates the process of tracking product prices on Amazon. Using Python, the script extracts product information such as title and price from an Amazon product page, stores the data in a CSV file, and continuously monitors price changes over time. The project can also send an email notification when the product price falls below a specified threshold.

Project Summary

  • Dataset: Amazon Product Price Data
  • Tool: Python, Jupyter Notebook
  • Skills: Web Scraping, BeautifulSoup, Requests, CSV Handling, Pandas, Automation, Email Notifications
  • Objective: The project demonstrates practical applications of web scraping, data collection, automation, file handling, and email notifications using Python.

Project Goals

  • Extract product details from Amazon using web scraping.
  • Store historical price data in a CSV file.
  • Monitor price fluctuations automatically.
  • Generate alerts when the product price drops below a target value.
  • Gain hands-on experience with Python automation and web scraping.
